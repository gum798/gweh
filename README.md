# 오늘의 괘 (Today's Gweh)

`<sub>`*괘는 징조, Gweh means Omen*`</sub>`

> *"하늘의 기운과 대지의 맥박, 달의 속삭임이 하나 되어 당신의 오늘을 비춥니다."*

---

## ☽ 소개

우주는 끊임없이 우리에게 신호를 보내고 있습니다.

**오늘의 괘**는 고대의 지혜와 현대의 데이터를 융합하여, 천상과 지상의 기운을 해석하는 신비로운 오라클입니다.

날씨의 기압, 달의 위상, 대지의 움직임... 이 모든 것이 하나로 어우러져 오늘 당신에게 필요한 메시지를 전합니다.

---

## ☾ 징조의 원천

```
    ◯ 대기의 기운 — 기압이 알려주는 우주의 숨결
    ☽ 달의 속삭임 — 월령이 비추는 내면의 흐름
    ⏃ 대지의 맥박 — 지진파가 전하는 땅의 메시지
    ✧ 하늘의 화폭 — NASA가 포착한 우주의 장관
```

---

## ✧ 시작하기

### 필요한 제물

- Node.js 18 이상
- npm 또는 yarn

### 의식 준비

```bash
# 의존성 소환
npm install

# 개발 서버 점화
npm run dev

# 생산용 빌드 결정화
npm run build
```

### 신비의 열쇠 (API Keys)

`.env` 파일을 생성하고 다음의 열쇠들을 준비하세요:

```env
VITE_OPENWEATHER_API_KEY=your_openweather_key
VITE_NASA_API_KEY=your_nasa_api_key
```

- [OpenWeatherMap](https://openweathermap.org/api) — 대기의 신탁
- [NASA APOD](https://api.nasa.gov/) — 우주의 화폭

---

## ☯ 점괘의 해석

### 복합 징조

우주의 여러 요소가 특정 조합을 이룰 때, 특별한 메시지가 현현합니다:

| 조합                             | 의미                         |
| -------------------------------- | ---------------------------- |
| 높은 기압 + 보름달 + 고요한 대지 | 우주가 당신 편입니다         |
| 낮은 기압 + 활발한 지각 활동     | 관망하며 에너지를 축적하세요 |
| 새달 + 맑은 하늘                 | 새로운 의도를 품기 완벽한 때 |
